# LuxeLacquer Nail Atelier

A complete modern interactive landing page for a luxury nail salon. The site includes a sticky responsive navigation bar, animated 3D nail polish hero scene, service menu, interactive look book, artist cards, and a polished booking form.

## Features

- Three.js-powered 3D polish bottle showcase with pointer-responsive lighting and motion.
- Modern glassmorphism design, reveal-on-scroll animations, animated marquee, and hover tilt interactions.
- Responsive sections for services, consultation experience, gallery, nail artists, and appointment requests.
- No build step required; the site runs as static HTML, CSS, and JavaScript.

## Run locally

Start a static server from the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.
